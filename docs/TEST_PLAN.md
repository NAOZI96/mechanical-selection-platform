# 测试计划

文档版本：0.1.0  
目标：证明数值正确、边界受控、报告一致、模块可扩展，并在低资源服务器上不干扰既有服务

## 1. 测试原则与门禁

- 公式实现必须先有独立期望值，再写生产代码；禁止用被测函数生成自身期望值。
- 每个公式 ID 至少有正常、边界和异常测试。
- 比较使用明确绝对/相对容差；整数圈数、层数、状态和警告代码必须精确相等。
- 中间步骤与最终结果都测试，避免“最终数值碰巧正确”。
- 所有金样均记录 `calculation_model_version`；模型变更不得静默覆盖旧期望。
- P0/P1 缺陷清零，核心金样、单位、边界、快照/报告一致性测试全绿后方可发布。

## 2. 测试层级

1. 单元测试：单位转换、公式、离散循环、舍入、警告。
2. 模块契约测试：注册字段、输入模型、纯计算、报告上下文和版本。
3. API 集成测试：状态码、JSON schema、数据库事务和读取不重算。
4. 报告测试：HTML 结构、PDF 文本/分页/字体与视觉快照。
5. 数据测试：迁移、约束、备份、恢复、WAL 和磁盘故障。
6. 性能/资源测试：单 worker、并发请求、PDF 限流、内存/磁盘。
7. 工程审核：由机械工程师独立复核公式口径、参数来源和免责声明。

## 3. 金样 A-001（完整输入、6 层满足）

输入仅作测试，不是推荐默认：`F_r=100 kN`、`d=20 mm`、`v=12 m/min`、`L_t=300 m`、`K_s=1.2`、`η=0.85`、`n_m=1470 r/min`、`D_c=400 mm`、`B=800 mm`、`z_max=6`、`K_p=1.05`、`b=20 mm/侧`、`M=1`、`K_b=1.5`、`N_dead=0`。

独立计算基准（保留足够位数）：

| 项目 | 期望值 |
|---|---:|
| 节距 `p` | 0.021 m |
| 可用宽度 `B_u` | 0.760 m |
| 每完整层圈数 | 36 |
| 设计拉力 | 120000 N |
| 理论负载功率 | 24000 W |
| 最低所需电机功率 | 28235.2941176471 W |
| 第 1–6 层工作直径 | 0.42, 0.46, 0.50, 0.54, 0.58, 0.62 m |
| 第 1–6 层容量 | 47.5068965982, 52.0302669750, 56.5537210266, 61.0772401619, 65.6008109173, 70.1244233030 m |
| 6 层最大/实际层完整容量 | 352.8933589819 m |
| 实际层数 | 6 |
| 末层目标使用圈数 | 8.8459667309 圈 |
| 容量余量 | 52.8933589819 m（17.6311196606%） |
| 空/满卷转速 | 9.0945681767 / 6.1608365068 r/min |
| 空/满卷参考速比 | 161.6349420272 / 238.6039620401 |
| 中径名义参考速比 | 200.1194520337 |
| 低速轴静态保持制动力矩 | 46500 N·m |

若设置 `allow_forward_efficiency_as_reverse_approx=true` 并明确批准用 `η_back=0.85` 近似，则高速轴参考力矩为约 273.3661410573 N·m，并必须出现 `W_REVERSE_EFFICIENCY_APPROXIMATED`；未批准时值必须为 null/`review_required` 并出现 `W_REVERSE_EFFICIENCY_UNKNOWN`。

期望警告至少包含绳强度未校核、卷筒结构未校核、电机选型不完整、固定速比速度变化、静态制动限制、工作级别仅提示和参数来源待确认。

## 4. 关键功能用例

| ID | 场景 | 可验证期望 |
|---|---|---|
| `A-002` | `B` 缺失、`D_c` 存在 | 整数搜索得到最小圈数和面长；减小一个节距后容量必不足。 |
| `A-003` | `D_c` 缺失、批准 `R_Dd` 存在 | `D_c=R_Dd d`，等级 preliminary，来源进入报告。 |
| `A-004` | `D_c` 与 `R_Dd` 均缺失 | 功率可计算；所有依赖几何结果为 null/review_required；出现 `W_CORE_RULE_MISSING`。 |
| `A-005` | 给定面长容量不足 | `capacity_satisfied=false`，实际层数为 null；返回最大层数容量、缺口和最大层工作状态，状态带警告，不声称满足目标。 |
| `A-006` | 目标恰好等于累计层容量 | 实际层数不多算一层，余量为 0（容差内）。 |
| `A-007` | 可用宽度恰好等于整数倍节距 | 圈数精确为该整数，不因浮点误差少 1。 |
| `A-008` | `N_dead>0` | 只扣第一层可用容量；几何占位仍存在。 |
| `A-009` | `M>1` | 主功率/绳张力结果不变，只改变理想载荷端提示。 |
| `A-010` | 改大 `K_s` | 设计拉力和功率线性增加；低速制动力矩默认不变。 |
| `A-011` | 改大 `K_b` | 制动力矩线性增加；驱动功率不变。 |
| `A-012` | 缺反向效率 | 高速轴参考值为 null/review_required，低速轴值仍可用。 |
| `A-013` | 固定速比矛盾 | 返回空/满卷速比范围和 `W_FIXED_RATIO_SPEED_VARIATION`。 |

## 5. 边界与非法输入

逐项测试 0、负数、极小正数、软上限、超软上限、NaN、Infinity、数值字符串、超长文本：

- `η=0`、`η>1`；`K_s<1`、`K_b<1`、`K_p<1`、`M<1`。
- `z_max=0`、小数、超过产品上限 100。
- `B=2b`、`B<2b`、`0 < B-2b < p`。
- 超大目标长度导致容量不足，但循环最多执行 `z_max`，不得失控。
- 恰好一层、末层部分圈、末层完整圈、死圈占满第一层。
- 文本包含 HTML/脚本、路径分隔符和 Unicode；报告必须转义，文件路径不可控。

## 6. 性质测试

在有效域内随机生成输入并验证：

- 各层 `D_j`、每圈长度和累计容量随层号严格增加（圈数相同且 d>0）。
- 固定其他量时，增加面长不会降低容量；增加最大层数不会降低最大容量。
- `capacity_at_actual_layers >= target`（成功满足时），前一层累计值 `< target`。
- `n_empty >= n_full`；`i_empty <= i_full`。
- SI 与等价显示单位换算得到相同规范化输入和结果。
- 所有返回数有限，未知结果只用 null。

## 7. API、数据和报告一致性

- POST 响应、GET 快照、HTML 与 PDF 的关键数值及模型版本一致。
- 修改当前配置/默认值后，读取旧记录不改变旧快照。
- 报告渲染器被替换为会调用计算器的测试桩时测试失败，确保禁止重算。
- 模拟数据库写失败：不返回成功 ID；模拟 PDF 失败：计算快照仍保留，报告状态 failed。
- PDF 检查中文字体嵌入/显示、长警告换页、逐层表头重复、页码、免责声明和无截断。

## 8. 模块扩展测试

构造不含业务意义的 `dummy_module`，实现完整协议。验收：自动出现在模块列表；统一计算路由可调用；快照可保存；报告壳可渲染；不修改 `winch_drum`、核心路由和数据库表。再用缺少版本、重复 ID 或会访问网络的非法模块验证启动检查失败。

方案 B 实现时必须复用同一契约测试套件，并另有独立公式金样；不得引用方案 A 内部 calculator。

## 9. 性能与资源验收

测试前记录同机既有服务 30 分钟基线。测试环境使用与生产相同容器限制：

- 计算接口：顺序 1000 次及并发 5，总错误率 0；p95 < 500 ms。
- PDF：连续 20 份及并发 5 个请求；实际渲染并发始终 1；p95 < 10 s 或返回受控限流，不发生 OOM。
- Web 容器持续内存不超过 512 MiB，压力结束后无持续增长趋势；不得以大量 Swap 换取通过。
- 数据库、WAL、日志、临时 PDF 和报告目录均受监控；临时文件在失败/超时后清理。
- 压测期间既有服务健康检查连续正常；若 CPU、内存或 I/O 明显恶化，则降低配额/并发再验收。

## 10. 验收证据

每次发布保存测试报告、覆盖率、金样差异、依赖清单、容器资源曲线、备份恢复记录、PDF 样张和机械工程师审核结论。所有“待确认”项必须有负责人和关闭证据，不能仅改文案隐藏。
