# 机械智选产品需求文档

> C-01～C-09 决策后定位：本产品只提供机械工程初算和设备初选，不提供施工设计、标准合规证明、型式认可、船级社或安全认证。MVP 只支持钢丝绳绞车/卷筒的正向稳态计算、逐层容绳、静态保持制动和电机稳态功率选档；不自动完成动态/应急制动、电机启动与热容量、绳端固定强度、钢丝绳强度寿命或卷筒结构强度。

文档版本：0.3.0

状态：Phase 4 回环部署的软件验收完成；专项机械校核与公共发布待批准
首发模块：方案 A——绞车与卷筒选型助手

## 1. 产品目标

“机械智选”是面向机械设计人员的轻量级计算与初选网站。系统用可审计的确定性 Python 代码执行计算，保留输入、单位换算、公式、模型版本、假设、警告和报告，帮助工程师更快完成方案比较，但不替代设计审批、标准核查、供应商确认或注册工程师签字。

第一阶段只交付方案 A。平台主页作为统一模块中心，应明确区分已开放和规划中的能力。平台结构允许后续以注册模块的方式加入方案 B（机械传动快速校核）以及丝杆、步进电机、同步带、齿轮、轴承、气缸和电机功率等模块。

## 2. 用户与核心场景

- 机械设计工程师：录入已知工况，得到可追溯的计算过程、候选参数和风险提示。
- 技术评审角色：查看公式、假设、模型版本和警告，判断结果是否可用于下一步设计。
- 系统维护者：不修改平台核心流程即可注册新计算模块并增加测试。

典型流程：选择模块 → 填写输入 → 前端单位提示与基础校验 → 后端转为 SI → 确定性计算 → 展示结果分类与警告 → 保存计算快照 → 查看 HTML 报告 → 按需生成 PDF。

## 3. MVP 范围

### 3.1 必须交付

- 方案 A 输入、校验、SI 单位转换、逐层离散容绳计算。
- 输出设计拉力、理论负载功率、最低所需电机功率、卷筒几何、各层数据、卷筒转速、参考减速比和制动力矩参考值。
- 每项结果标注 `calculated`（模型内精确计算）、`preliminary`（工程初选）或 `review_required`（需人工复核）。
- 将公式标识、模型版本、原始输入、SI 输入、默认值、假设、警告与结果保存为不可变计算快照。
- HTML 报告与 PDF 报告；两者内容来源于同一报告上下文。
- 页面及报告包含关键参数汇总表和按严重度排序的参数警告。
- 平台主页、模块注册、模块列表、统一页面入口和统一计算接口。
- 已注册模块从运行时注册表自动进入主页；规划模块只作路线展示，不生成可点击入口或计算 API。
- 单 worker、SQLite、Docker Compose 部署及备份/恢复说明。
- 中文界面；桌面端优先，并保证常见手机宽度可阅读。

### 3.2 暂不开发

- 方案 B 及其他计算模块的业务公式实现（仅预留接入契约）。
- 用户注册、组织/角色、付费、审批流、电子签名与多人实时协作。
- CAD/CAE、有限元、疲劳寿命、卷筒筒体/法兰/焊缝强度、轴及轴承寿命、排绳器设计。
- 钢丝绳/合成绳强度选型、破断拉力核验、滑轮直径、压绳器、乱绳和入绳偏角校核。
- 减速器、电机、制动器品牌型号数据库与自动采购选型。
- 动态起制动、冲击、热平衡、载荷谱、扭振、过载能力和工作制计算。
- 大模型计算、自动替代工程师确认、自动引用未核实标准。
- React/Vue、Node 构建链、Redis、Celery、PostgreSQL、多 worker 和分布式任务。

## 4. 方案 A 产品需求

### 4.1 输入

| 字段 | 显示单位 | 必填 | 产品说明 |
|---|---:|---:|---|
| 拉力输入值 | kN | 是 | 配合位置（载荷端/卷筒绳端）和类型（额定/设计/最大）显式解释；后端统一换算。 |
| 缆绳直径 | mm | 是 | 仅用于几何；不代表绳强度已满足。 |
| 收放绳速度 | m/min | 是 | 配合位置（载荷端/卷筒绳端）显式解释；后端统一换算。 |
| 目标容绳量 | m | 是 | 几何容绳目标，不含未声明的固定死圈和外部余绳。 |
| 使用系数 | — | 是 | 用于驱动设计拉力；来源必须由工程师填写或确认。 |
| 总传动效率 | — | 是 | 电机到卷筒的正向总效率。 |
| 电机额定转速 | r/min | 是 | 名牌/候选系统的额定机械转速。 |
| 电机类型 | 枚举/文本 | 是 | 用于提示，不自动推断过载能力或工作制。 |
| 卷筒芯径 | mm | 否 | 未提供时优先使用批准 D/d，否则使用显式项目初选比 20；初选结果不代表标准合规。 |
| 卷筒有效长度 | mm | 否 | MVP 定义为两法兰内侧间可排绳总轴向长度，包含两侧余量。 |
| 最大缠绕层数 | 层 | 是 | 正整数。 |
| 排绳节距修正系数 | — | 是 | 节距 `p = k_p d`。 |
| 两侧余量 | mm/侧 | 是 | 每侧分别扣除。 |
| 滑轮组倍率与效率 | — | 是 | 只在输入位置统一时作用一次；后续公式只用换算后的卷筒端值。 |
| 制动安全系数 | — | 是 | 仅用于静态保持制动参考计算。 |
| 工作级别 | 文本/枚举 | 是 | 仅提示；MVP 不据此自动选系数。 |

在进入计算前，后端统一转换为 SI；原始显示单位和值仍需保存在快照中。详细语义与边界见 `CALCULATION_SPEC.md`。

### 4.2 输出与可信度

| 输出 | 分类 | 说明 |
|---|---|---|
| 设计拉力、理论负载功率、最低所需电机功率 | calculated | 在已声明输入与公式下确定；“建议电机功率”若指标准额定档位，则仍需工程初选。 |
| 每层圈数、每层容绳量、总容绳量、余量、实际缠绕层数 | calculated | 逐层离散螺旋长度模型内的确定性结果。 |
| 空/满绳工作直径、对应转速 | calculated | “工作直径”为绳中心线直径；容量不足时满绳字段为空，改报允许最大层值。 |
| 芯径建议、有效长度建议、参考减速比 | preliminary/review_required | 依赖已确认几何规则、速度控制策略和工程约束。 |
| 低速轴制动力矩、高速轴参考值 | preliminary | 静态保持参考；必须复核制动工况、反向效率、安装轴与法规/标准。 |
| 工作级别、滑轮组换算提示 | informational | 不直接改变 MVP 主计算，避免重复系数。 |

### 4.3 用户可见状态

- 成功：计算完成且无阻断项。
- 成功但需复核：数值可生成，但存在工程警告或初选项。
- 容量不足：保留计算和最大层结果，满绳字段为空，并以高严重度警告阻止误读。
- 校验失败：返回字段级错误，不创建成功计算记录。

## 5. 非功能需求

- 可追溯：每次成功计算保存 `module_id`、`module_version`、`calculation_model_version` 和公式版本。
- 可重复：相同模型版本与规范化输入应得到相同结果；报告不得重新计算。
- 安全：后端不执行用户代码；输入限长；报告转义；不在日志记录敏感请求全文。
- 性能：目标环境下普通计算请求 p95 < 500 ms（不含首次 PDF 字体加载），单次 PDF p95 < 10 s；PDF 串行或限并发 1。
- 资源：应用容器设置内存上限与日志轮转；SQLite/WAL、报告缓存和备份均设容量策略。
- 可用性：业务计算失败不得影响同机其他服务；容器有健康检查和重启策略，但不得无限重启风暴。
- 可维护：模块之间不得直接导入彼此的业务实现；公共契约稳定、版本显式。

## 6. 验收标准

1. 注册表能列出方案 A；主页能区分已开放/规划状态；加入一个最小演示模块无需修改方案 A 或路由核心代码，并能自动替换同 ID 的规划卡片。
2. 所有输入均有字段说明、单位、范围、默认来源和错误消息；后端为最终校验权威。
3. 任一可验证案例的各层圈数与螺旋长度可手算复核，结果不是总体积估算。
4. 若芯径缺失且没有已批准 D/d，系统只使用显式标记的项目初选比 20，并把芯径及派生建议标为 `preliminary`、显示标准条款未确认警告。
5. 报告包含原始输入、SI 输入、公式、代入值、过程结果、假设、警告、分类、模型版本、生成时间和免责声明。
6. HTML、PDF、API 与数据库快照的关键结果在规定舍入前完全一致。
7. 使用系数不会在设计拉力和制动力矩中无说明地重复乘用；滑轮倍率不会重复作用于绳张力。
8. 单 worker 和限定 PDF 并发下完成负载与内存测试，不突破部署文档的资源预算。
9. 数据库可执行备份与恢复演练；损坏/只读/磁盘不足时给出受控错误。
10. 文档中的字段名、公式 ID、版本规则、状态枚举和默认值表一致。

## 7. 成功指标

- 100% 已发布公式具有公式 ID、单位、适用条件和测试。
- 100% 成功计算保存模型版本及输入快照。
- 所有高严重度警告在 HTML/PDF 中可见且不可被静默省略。
- 受控上线前无未解决的软件 P0/P1 缺陷；核心金样、报告、资源和恢复门禁全部通过。
