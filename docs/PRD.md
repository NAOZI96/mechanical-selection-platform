# 机械智选产品需求文档

> 产品定位：本产品只提供机械工程初算、受控工作表和候选值比较，不提供施工设计、标准合规证明、型式认可、船级社或安全认证。`winch_drum` 处于工程评审，八个 Phase 7 扩展模块处于内部测试；任何结果均不得绕过专项校核、制造商确认或具备资质的工程审批。

文档版本：0.5.0

状态：首发模块 Phase 4 回环部署的软件验收完成；Phase 8 九模块产品候选版已完成本地实现与回归，尚未远程部署或应用迁移 `005`，专项机械校核与公共发布待批准
模块状态：`winch_drum=engineering_review`；八个扩展模块均为 `internal_testing`

## 1. 产品目标

“机械智选”是面向机械设计人员的轻量级计算与初选网站。系统用可审计的确定性 Python 代码执行计算，保留输入、单位换算、公式、模型版本、假设、警告和报告，帮助工程师更快完成方案比较，但不替代设计审批、标准核查、供应商确认或注册工程师签字。

平台主页作为统一模块中心，明确区分软件可进入状态与工程发布状态。当前已注册首发 `winch_drum` 以及机械传动、齿轮、轴承与轴、丝杠、同步带、电机驱动、步进电机和气缸八个受控工程工作表；用户可按名称、说明、能力和分类快速找到入口。

## 2. 用户与核心场景

- 机械设计工程师：录入已知工况，得到可追溯的计算过程、候选参数和风险提示。
- 技术评审角色：查看公式、假设、模型版本和警告，判断结果是否可用于下一步设计。
- 系统维护者：不修改平台核心流程即可注册新计算模块并增加测试。

典型流程：选择模块 → 填写输入 → 前端单位提示与基础校验 → 后端转为 SI → 确定性计算 → 展示结果分类与警告 → 保存计算快照 → 查看 HTML 报告 → 按需生成 PDF。

## 3. MVP 范围

### 3.1 必须交付

- 方案 A 输入、校验、SI 单位转换、逐层离散容绳计算。
- 输出设计拉力、理论负载功率、最低所需电机功率、卷筒几何、各层数据、卷筒转速、参考减速比和制动力矩参考值。
- 每项结果标注 `calculated`（模型内精确计算）、`preliminary`（工程初选）或 `review_required`（需人工复核）。
- 将公式标识、模型版本、原始输入、SI 输入、默认值、假设、警告、结果和计算当时工程发布状态保存为不可变计算快照。
- HTML 报告与 PDF 报告；两者内容来源于同一报告上下文。
- 页面及报告包含关键参数汇总表和按严重度排序的参数警告。
- 可直接试用的产品主页、模块注册、可搜索/分类筛选的模块列表、统一页面入口和统一计算接口；无需第三方动画运行库或前端 CDN。
- 九个已注册模块从运行时注册表自动进入主页；规划模块只作路线展示，不生成可点击入口或计算 API。
- 八个扩展模块提供独立输入校验、确定性公式步骤、来源状态、结果分类、警告、快照及同源 HTML/PDF 报告。
- 软件可运行状态与工程发布状态分离，页面和 API 均不得把 `internal_testing` 或 `engineering_review` 表述为制造、采购或安全工程放行。
- `/docs` 与 `/redoc` 提供服务端渲染、无需内联/第三方脚本的同源 API 参考，并可在严格 CSP 下阅读。
- 新计算写入 snapshot/report context schema v4；旧记录未保存当时状态时统一显示 `legacy_unknown`，不得按当前状态补写或推断。
- 遗留缓存 PDF 经路径、大小和 SHA-256 校验后可继续下载并显式告警；没有有效缓存的旧 PDF 返回受控 409，要求重新计算生成新版记录。
- 单 worker、SQLite、Docker Compose 部署及备份/恢复说明。
- 中文界面；桌面端优先，并保证常见手机宽度可阅读。

### 3.2 暂不开发

- 用户注册、组织/角色、付费、审批流、电子签名与多人实时协作。
- CAD/CAE、有限元、详细疲劳与可靠性、卷筒筒体/法兰/焊缝强度、轴键槽/轴肩/临界转速及轴承修正寿命、排绳器设计。
- 钢丝绳/合成绳强度选型、破断拉力核验、滑轮直径、压绳器、乱绳和入绳偏角校核。
- 减速器、电机、制动器、轴承、同步带、丝杠、气缸等品牌型号数据库与自动采购选型。
- 未在各模块计算规格中明确列出的动态起制动、冲击、热平衡、载荷谱、扭振、过载能力和工作制计算。
- 大模型计算、自动替代工程师确认、自动引用未核实标准。
- React/Vue、Node 构建链、Redis、Celery、PostgreSQL、多 worker 和分布式任务。

## 4. 方案 A 产品需求

### 4.1 输入

| 字段 | 显示单位 | 必填 | 产品说明 |
|---|---:|---:|---|
| 拉力输入值 | kN | 是 | 配合位置（载荷端/卷筒绳端）和类型（额定/设计/最大）显式解释；后端统一换算。 |
| 缆绳直径 | mm | 是 | 仅用于几何；不代表绳强度已满足。 |
| 收放绳速度 | m/min | 是 | 配合位置（载荷端/卷筒绳端）显式解释；后端统一换算。 |
| 目标容绳量 | m | 是 | 几何容绳目标，不含未声明的固定死圈和外部余绳。 |
| 使用系数 | — | 是 | 用于驱动设计拉力；来源必须由工程师填写或确认。 |
| 总传动效率 | — | 是 | 电机到卷筒的正向总效率。 |
| 电机额定转速 | r/min | 是 | 名牌/候选系统的额定机械转速。 |
| 电机类型 | 枚举/文本 | 是 | 用于提示，不自动推断过载能力或工作制。 |
| 卷筒芯径 | mm | 否 | 未提供时优先使用批准 D/d，否则使用显式项目初选比 20；初选结果不代表标准合规。 |
| 卷筒有效长度 | mm | 否 | MVP 定义为两法兰内侧间可排绳总轴向长度，包含两侧余量。 |
| 最大缠绕层数 | 层 | 是 | 正整数。 |
| 排绳节距修正系数 | — | 是 | 节距 `p = k_p d`。 |
| 两侧余量 | mm/侧 | 是 | 每侧分别扣除。 |
| 滑轮组倍率与效率 | — | 是 | 只在输入位置统一时作用一次；后续公式只用换算后的卷筒端值。 |
| 制动安全系数 | — | 是 | 仅用于静态保持制动参考计算。 |
| 工作级别 | 文本/枚举 | 是 | 仅提示；MVP 不据此自动选系数。 |

在进入计算前，后端统一转换为 SI；原始显示单位和值仍需保存在快照中。详细语义与边界见 `CALCULATION_SPEC.md`。

### 4.2 输出与可信度

| 输出 | 分类 | 说明 |
|---|---|---|
| 设计拉力、理论负载功率、最低所需电机功率 | calculated | 在已声明输入与公式下确定；“建议电机功率”若指标准额定档位，则仍需工程初选。 |
| 每层圈数、每层容绳量、总容绳量、余量、实际缠绕层数 | calculated | 逐层离散螺旋长度模型内的确定性结果。 |
| 空/满绳工作直径、对应转速 | calculated | “工作直径”为绳中心线直径；容量不足时满绳字段为空，改报允许最大层值。 |
| 芯径建议、有效长度建议、参考减速比 | preliminary/review_required | 依赖已确认几何规则、速度控制策略和工程约束。 |
| 低速轴制动力矩、高速轴参考值 | preliminary | 静态保持参考；必须复核制动工况、反向效率、安装轴与法规/标准。 |
| 工作级别、滑轮组换算提示 | informational | 不直接改变 MVP 主计算，避免重复系数。 |

### 4.3 用户可见状态

- 成功：计算完成且无阻断项。
- 成功但需复核：数值可生成，但存在工程警告或初选项。
- 容量不足：保留计算和最大层结果，满绳字段为空，并以高严重度警告阻止误读。
- 校验失败：返回字段级错误，不创建成功计算记录。

## 5. 八个扩展模块产品需求

八模块均定位为“受控工程工作表”：允许工程师录入已知工况和有来源的候选值，输出可复算的基础结果与缺口，不内置未经确认的标准系数或产品能力。

| 模块 | 已实现软件范围 | 明确不代表 |
|---|---|---|
| `transmission_check` | 1～4 级正向稳态传动链速比、效率、转速、转矩、功率和候选额定转矩比较 | 反驱、冲击、热平衡、齿轮箱或联轴器正式选型 |
| `gear_drive` | 标准直齿外啮合基础几何、名义力、节线速度及用户给定限值比较 | 齿根/接触强度、修形、寿命、润滑和制造放行 |
| `shaft_bearing` | 给定 X/Y/p 的 L10 基本额定寿命及实心圆轴名义弯扭应力 | 修正寿命、轴疲劳/挠度/临界转速、键槽和配合设计 |
| `lead_screw` | 等效方牙提升/下降转矩、效率、自锁、功率及 Euler 理论临界载荷 | 梯形牙精确接触、磨损、临界转速、螺母/支承选型 |
| `synchronous_belt` | 速比、节径、带速、设计功率、圆周力、近似带长和啮合齿数 | 带型/带宽/寿命、张紧、轴载荷和制造商容量放行 |
| `motor_drive` | 两段稳态循环的连续、峰值、RMS 转矩和功率折算 | 启动/加速惯量、热容量、供电、控制器及完整工作制选型 |
| `stepper_motor` | 刚性传动惯量折算、恒加速转矩、脉冲频率和曲线工作点比较 | 惯性加速传动损耗口径、共振、失步、热、驱动电压、定位精度及完整曲线插值 |
| `pneumatic_cylinder` | 双作用单杆气缸理论伸缩力、负载余量、扫掠体积和理想参考耗气量 | 摩擦/压降/缓冲/速度、安装侧载、屈曲和阀管路选型 |

每个工作表必须：

- 要求 `basis_source_status` 与非空 `basis_reference`，并把采用的依据保存到快照；
- 对参与合格性比较的候选额定值要求对应来源状态和引用；
- 缺少可选候选值时保持基础计算可运行，但将不能给出的选型结论标为待校核；
- 显示 `internal_testing`，并在页面、HTML/PDF 和免责声明中阻止制造、采购或安全放行误读。

完整需求边界见 [`MODULE_REQUIREMENTS.md`](MODULE_REQUIREMENTS.md)，公式和测试证据见 [`EXPANDED_MODULES_CALCULATION_SPEC.md`](EXPANDED_MODULES_CALCULATION_SPEC.md) 与 [`EXPANDED_FORMULA_TEST_MATRIX.md`](EXPANDED_FORMULA_TEST_MATRIX.md)。

## 6. 非功能需求

- 可追溯：每次成功计算保存 `module_id`、`module_version`、`calculation_model_version` 和公式版本。
- 可重复：相同模型版本与规范化输入应得到相同结果；报告不得重新计算。
- 安全：后端不执行用户代码；输入限长；报告转义；不在日志记录敏感请求全文；应用返回同源 CSP、防嵌入、防 MIME 嗅探、最小来源与权限策略。
- 性能：目标环境下普通计算请求 p95 < 500 ms（不含首次 PDF 字体加载），单次 PDF p95 < 10 s；PDF 串行或限并发 1。
- 资源：应用容器设置内存上限与日志轮转；SQLite/WAL、报告缓存和备份均设容量策略。
- 可用性：业务计算失败不得影响同机其他服务；容器有健康检查和重启策略，但不得无限重启风暴。启动必须验证 PDF 字体和报告目录可写；ready 端点保持浅层，不用昂贵完整性检查或 PDF 渲染阻塞探针。
- 可维护：模块之间不得直接导入彼此的业务实现；公共契约稳定、版本显式。
- 缓存：静态资源允许一天共享缓存；计算和报告一律 `no-store` 且禁止索引；其他页面/API 每次重新验证。

## 7. 验收标准

1. 注册表精确列出 9 个模块及其发布状态；主页能区分软件可进入、工程评审、内部测试和规划状态。
2. 所有输入均有字段说明、单位、范围、默认来源和错误消息；后端为最终校验权威。
3. 任一可验证案例的各层圈数与螺旋长度可手算复核，结果不是总体积估算。
4. 若芯径缺失且没有已批准 D/d，系统只使用显式标记的项目初选比 20，并把芯径及派生建议标为 `preliminary`、显示标准条款未确认警告。
5. 报告包含原始输入、SI 输入、公式、代入值、过程结果、假设、警告、分类、模型版本、生成时间和免责声明。
6. HTML、PDF、API 与数据库快照的关键结果在规定舍入前完全一致。
7. 使用系数不会在设计拉力和制动力矩中无说明地重复乘用；滑轮倍率不会重复作用于绳张力。
8. 单 worker 和限定 PDF 并发下完成负载与内存测试，不突破部署文档的资源预算。
9. 数据库可执行备份与恢复演练；损坏/只读/磁盘不足时给出受控错误。
10. 文档中的字段名、公式 ID、版本规则、状态枚举和默认值表一致。
11. 八个扩展模块均可完成页面 → schema → POST → 快照 GET → HTML → PDF 链路，且不直接导入其他模块业务计算。
12. 八模块软件验收不自动提升工程状态；逐模块标准、制造商数据、独立复算和专项机械校核有关闭证据后才可发布。
13. 主页九模块可按规范化关键词与分类筛选，计数和空状态准确，键盘/移动端可用。
14. `/docs` 与 `/redoc` 在严格 CSP 下不加载外部或内联脚本，端点清单与当前 OpenAPI schema 一致。
15. 新计算持久化当次发布状态；迁移前旧行保持 `NULL`/`legacy_unknown`，当前注册状态变化不改写历史报告。
16. 遗留有效缓存 PDF 可审计下载；无有效缓存的旧 PDF 返回 `409 LEGACY_RELEASE_STATUS_MISSING` 且不启动渲染。
17. 目标机发布前在线备份并应用迁移 `005`，完成启动字体/目录、浅层 ready、安全/缓存头、旧数据、资源和恢复冒烟。

## 8. 成功指标

- 100% 已发布公式具有公式 ID、单位、适用条件和测试。
- 100% 成功计算保存模型版本及输入快照。
- 所有高严重度警告在 HTML/PDF 中可见且不可被静默省略。
- 受控上线前无未解决的软件 P0/P1 缺陷；核心金样、报告、资源和恢复门禁全部通过。
