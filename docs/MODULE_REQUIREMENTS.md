# 八个扩展模块需求基线

文档版本：0.1.0
状态：独立需求分析完成；基础计算模型进入软件实现，工程发布仍受逐模块门禁控制
适用模块：`transmission_check`、`gear_drive`、`shaft_bearing`、`lead_screw`、`synchronous_belt`、`motor_drive`、`stepper_motor`、`pneumatic_cylinder`

## 1. 结论与使用边界

仓库已经明确命名八个后续模块，但此前只有首页摘要和能力标签；除 `transmission_check` 外，没有独立计算规格、正式标准版本、制造商数据集、公式测试矩阵或机械审核结论。

本轮采用以下可执行边界：

- 可由基础物理、几何和运动学直接复核的公式，形成确定性 Python 功能；
- 所有材料许用值、寿命系数、服务系数、制造商额定能力和转矩—转速曲线均由用户显式输入；
- 每次计算必须保存来源状态和依据版本；
- 缺候选额定值或来源待确认时，候选结论为 `null + review_required + reason`；
- 注册成功只表示软件可进入，不表示工程已放行；
- 模块初始发布状态统一为 `internal_testing`；
- 模块可用于受控初算和已知候选数据校核，不得直接替代制造、采购、安全认证、正式标准核查或工程师签字。

## 2. 公共用户流程

目标用户包括机械设计工程师、设备集成工程师、产品应用工程师和技术评审者。

统一流程：

1. 从平台目录选择模块并确认模块发布状态。
2. 按页面显示单位录入工况、候选参数、来源状态和依据版本。
3. 后端通过 Pydantic 完成严格类型、有限数、字段范围和跨字段校验。
4. 模块显式转换为 SI，不从页面执行公式。
5. 纯 Python 计算器生成结果等级、公式步骤、警告和未完成专项校核。
6. 应用保存不可变快照，HTML 与 PDF 只读取同一报告上下文。
7. 使用者依据报告中的来源、警告和专项校核清单决定是否进入下一步工程审核。

## 3. 公共软件要求

### 3.1 输入与来源

- 数值只接受 JSON number，不接受布尔值、数值字符串、NaN 或 Infinity。
- 所有物理量名称包含显示单位或 SI 单位。
- 工程系数和候选额定数据不得存在无来源的隐藏默认值。
- 每个模块至少保存 `basis_source_status` 和 `basis_reference`。
- 用户示例只作为公式回归算例，不是推荐参数。

### 3.2 结果与警告

- 标量结果统一为 `value`、`unit`、`classification`、`formula_ids`、可选 `reason`。
- 结果等级限定为 `calculated`、`preliminary`、`review_required`、`informational`。
- 未知结果必须使用 `null`，不能用 0 或空字符串代替。
- 警告包含稳定代码、严重度、标题、消息、影响结果和建议动作。
- 计算状态只由警告决定为 `completed` 或 `completed_with_warnings`。

### 3.3 确定性与解耦

- `calculator.py` 不访问 FastAPI、SQLite、文件、网络、时钟或报告渲染器。
- 模块之间不导入彼此的 calculator。
- 相同模型版本和相同 SI 输入必须产生相同数值结果、步骤和警告。
- 任何候选搜索只能遍历用户提供的有限候选集合。

### 3.4 发布状态

目录访问状态与工程发布状态分离：

| 状态 | 含义 |
|---|---|
| `planned` | 尚未注册，无页面和计算 API。 |
| `internal_testing` | 软件功能可进入，仅用于受控测试与初算。 |
| `engineering_review` | 公式、标准和数据正在独立机械审核。 |
| `released` | 对该模块声明的有限适用范围已完成软件与工程门禁。 |

## 4. 模块需求

### 4.1 `transmission_check` 机械传动快速校核

用户任务：把已知输入端稳态工况沿有序传动级传播，检查累计速比、效率、输出速度/转矩/功率和候选接口额定能力。

首版输入：

- 输入转速、输入转矩；
- 1～4 级传动的级名称、速比、正向效率及各自来源；
- 可选候选输出额定转矩；
- 依据来源状态和版本。

首版输出：

- 累计速比和累计效率；
- 逐级输出速度、输出转矩和输出功率；
- 总输入功率、最终输出速度/转矩/功率；
- 可选候选转矩利用率、余量及满足状态。

首版不覆盖：单个齿轮/轴/轴承强度、反向效率、反驱、自锁、瞬态冲击、扭振和热容量。

工程发布补充：冻结速比正负约定、反向传动模型、效率证据、峰值/载荷谱和接口额定值来源。

### 4.2 `gear_drive` 齿轮传动基础设计

用户任务：对一对标准直齿外啮合圆柱齿轮完成基础几何、速比、啮合力、节线速度和制造商能力校核。

首版输入：

- 模数、主动/从动轮齿数和压力角；
- 主动轮转矩、转速、单级效率；
- 可选制造商许用圆周力和最大节线速度；
- 依据来源状态和版本。

首版输出：

- 两轮分度圆直径、中心距、实际速比和从动轮转速；
- 圆周力、径向力、节线速度和输出转矩；
- 可选圆周力利用率、速度利用率及满足状态。

首版适用范围：无变位的标准直齿外啮合基础几何。

首版不覆盖：齿根弯曲强度、接触强度、变位、根切/干涉、斜齿/锥齿/蜗杆/行星、材料热处理、精度、润滑、热、噪声和寿命。

工程发布补充：选定正式齿轮标准及版本，冻结强度公式族、材料许用值和全部载荷系数，并提供独立强度金样。

### 4.3 `shaft_bearing` 轴与轴承基础校核

用户任务：用已知载荷和制造商轴承额定数据计算等效动载荷与基本额定寿命，同时对实心圆轴的名义弯扭组合应力做基础校核。

首版输入：

- 径向载荷、轴向载荷、制造商系数 X/Y；
- 基本额定动载荷 C、寿命指数 p、转速；
- 轴弯矩、扭矩、直径和可选许用 von Mises 应力；
- 依据来源状态和版本。

首版输出：

- 等效动载荷、L10 百万转和 L10 小时；
- 轴名义弯曲应力、扭转剪应力和 von Mises 应力；
- 可选许用应力利用率、余量及满足状态。

首版不覆盖：支承反力求解、3D 载荷、台阶/键槽/圆角应力集中、疲劳、挠度、临界转速、轴承静载、润滑、污染、可靠度修正、配合/游隙和配对轴承载荷分配。

工程发布补充：冻结轴系梁模型、疲劳/刚度范围、轴承寿命修正方法和制造商目录版本。

### 4.4 `lead_screw` 滑动丝杠基础校核

用户任务：对等效方牙滑动丝杠计算导程角、提升/下降转矩、效率、速度、功率、自锁和 Euler 屈曲。

首版输入：

- 轴向载荷、导程、螺纹中径、摩擦系数和转速；
- 根径、无支承长度、弹性模量和用户显式给定的有效长度系数；
- 可选候选产品许用轴向载荷；
- 依据来源状态和版本。

首版输出：

- 导程角、线速度、提升/下降转矩、提升效率和驱动功率；
- 自锁状态；
- Euler 理论临界载荷、理论利用率及比较状态；
- 可选候选许用轴向载荷利用率、余量及满足状态。

首版适用范围：等效方牙滑动丝杠、同轴压缩载荷和用户确认的端部系数。

首版不覆盖：梯形牙角修正、滚珠/滚柱丝杠、螺母 PV/磨损、寿命、临界转速、安装误差、导向摩擦和制造商产品选型。

工程发布补充：按丝杠家族拆分公式，冻结端部支承、屈曲安全系数、临界转速和寿命模型，并提供制造商额定数据；当前 Euler 比较未加入屈曲安全系数，不是稳定性放行结论。

### 4.5 `synchronous_belt` 同步带基础校核

用户任务：计算同步带轮几何、速比、带速、近似带长、包角、啮合齿数和制造商能力校核。

首版输入：

- 主/从动轮齿数、节距、中心距和主动轮转速；
- 传递功率和用户给定服务系数；
- 可选制造商许用有效拉力和最大带速；
- 依据来源状态和版本。

首版输出：

- 速比、从动轮转速、两轮节径和带速；
- 设计功率和有效圆周力；
- 开式传动近似带长、小轮包角和啮合齿数；
- 可选许用有效圆周力及最大带速满足状态。

首版不覆盖：具体齿形/系列自动选型、目录表插值、预紧、轴载、惰轮、标准带长选档、疲劳、温度/环境修正和采购型号。

工程发布补充：绑定制造商系列与修订版，冻结服务系数作用位置、最小齿数/啮合/带速边界和禁止外推规则。

### 4.6 `motor_drive` 电机与驱动功率基础校核

用户任务：在明确的两段工作循环下计算负载折算到电机轴的连续、峰值和 RMS 转矩以及候选额定能力。

首版输入：

- 两个稳态工作段各自的负载轴转矩、速度和持续时间；
- 传动速比和正向效率；
- 用户给定服务系数；
- 用户声明的工作制文本（仅记录，不自动映射标准热模型）；
- 可选候选额定转矩、峰值转矩、额定功率和最大速度；
- 依据来源状态和版本。

首版输出：

- 两个工作段的电机轴速度和折算转矩；
- 周期平均连续转矩、峰值转矩、RMS 转矩、计入一次服务系数的需求值和所需功率；
- 可选额定转矩、峰值转矩、功率和速度逐项满足状态。

首版适用范围：两个显式稳态段构成的周期；不计算加减速瞬态。

首版不覆盖：任意运动曲线、减速/再生、负载惯量自动计算、S1～S9 热模型、低速冷却、启动电流、变频器/制动电阻和产品曲线插值。

工程发布补充：限定电机/驱动家族，冻结工作制与热模型，接入带版本的转矩—转速和过载数据。

### 4.7 `stepper_motor` 步进电机基础校核

用户任务：对旋转负载计算惯量反射、加速和稳态转矩、工作转速、脉冲频率，并用指定驱动条件下的厂家动态转矩工作点校核。

首版输入：

- 负载惯量、转子惯量、传动速比和稳态负载转矩折算效率；
- 负载转矩、目标负载转速和加速时间；
- 每转整步数、微步细分数和用户给定服务系数；
- 候选曲线工作点速度、速度匹配容差及该点可用动态转矩；
- 可选制造商允许惯量比；
- 依据来源状态和版本。

首版输出：

- 折算负载惯量、总惯量、惯量比；
- 电机转速、角加速度、加速转矩、稳态转矩和所需峰值转矩；
- 脉冲频率和曲线工作点转矩满足状态；
- 可选惯量比满足状态。

首版不覆盖：负载惯性加速过程的传动损耗、保持转矩替代、整条曲线插值、共振、失步概率、温升、定位精度、丝杠/同步带直线换算和驱动器电流设定。

工程发布补充：保存完整厂家曲线和驱动条件，冻结插值/禁止外推策略以及共振和热边界。

### 4.8 `pneumatic_cylinder` 双作用气缸基础校核

用户任务：对双作用单杆气缸计算伸出/缩回有效面积与力、负载安全需求、余量和标准状态耗气量。

首版输入：

- 缸径、杆径和行程；
- 气缸接口供气绝压、环境绝压和参考状态绝压；
- 伸出/缩回外载和安全系数；
- 完整伸缩循环频率；
- 可选候选气缸最大供气绝压；
- 依据来源状态和版本。

首版输出：

- 伸出/缩回面积、有效压差和理论推/拉力；
- 伸出/缩回需求力、余量和满足状态；
- 两腔扫掠体积、单循环参考状态折算体积和每分钟耗气量；
- 可选候选压力额定满足状态。

首版不覆盖：阀/管路压降、背压、速度和瞬时流量、泄漏、温度变化、缓冲、侧载、活塞杆屈曲、安装附件、标准缸径系列和采购型号。

工程发布补充：冻结最低动态压力与背压口径、气体参考状态、压降/流量模型、缓冲/侧载/屈曲方法和制造商产品数据。

## 5. 模块间数据依赖

模块不得直接调用彼此计算器。后续如需组合计算，只允许通过显式、版本化并由用户确认的 DTO：

```text
winch_drum -> transmission_check / motor_drive
transmission_check -> gear_drive / synchronous_belt / motor_drive / shaft_bearing
gear_drive / synchronous_belt -> shaft_bearing
lead_screw -> motor_drive / stepper_motor / shaft_bearing
```

跨模块快照至少保存来源模块 ID、模型版本、计算 ID、字段和值；复制后形成下游不可变输入，不随上游记录变化而静默重算。

## 6. 统一验收门槛

每个模块转为 `released` 前必须同时满足：

1. 独立计算规格列出公式 ID、符号、单位、适用条件和不可计算路径。
2. 正常、边界、非法输入和缺数据路径测试完整。
3. 金样来自独立手算、审核表或可追溯工具，不调用生产函数生成期望。
4. 相同输入重复执行结果一致。
5. API、SQLite 快照、HTML 和 PDF 关键值同源。
6. 标准版本、条款或制造商数据修订可追溯。
7. 机械工程师完成适用范围与公式审核。
8. 九模块组合资源、PDF、数据库增长、备份恢复和目标容器回归通过。

## 7. 尚需项目负责人确认

- 每模块的行业、设备类型、司法辖区和适用标准；
- 齿轮、丝杠、电机等首发产品家族；
- 正式标准版本、条款、页码和使用许可；
- 制造商目录、曲线、修正表、修订号和更新策略；
- 项目安全系数、寿命、可靠度、工作制和环境边界；
- 独立金样及工程审核角色；
- 输出只用于方案初选，还是允许进入采购审批；
- 公网多用户使用时的记录所有权、访问控制、留存和隐私策略。
